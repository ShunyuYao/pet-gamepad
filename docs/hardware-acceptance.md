## 验收路径

1. 在独立测试 profile 安装候选插件，用户批准输入权限；不要安装进日常 profile。
2. 先打开设置原型，点击连接检测，按一次手柄按钮；记录浏览器是否报告 standard mapping。原型检测通过不等于宿主游戏窗口已通过。
3. 在候选宿主打开动作样例并授权，确认一次设备选择不会同时触发跳跃；松开按钮、摇杆回中后才允许动作。
4. 单按、短按、长按、连续按，左右摇杆各方向及扳机渐变；记录回中漂移，不凭型号猜测兼容。
5. 按住按钮/摇杆切到其他窗口、宿主控制栏和输入文本状态；回到游戏先松开回中，旧动作不能补发。
6. 按住时断开 USB 或蓝牙；确认中和且无物理松手攻击。重新连接后重新选择/回中。
7. 游戏中修改配置，确认显示待生效；进入菜单才应用，提示和有效绑定同步。关闭设置不终止提供方。
8. 停用/卸载插件、关闭/重载作品、切换账号，确认旧会话中和或失效；键鼠仍可用。
9. 从全新宿主进程读取已保存布局和死区，确认插件默认值没有覆盖。

原生窗口焦点测试需要用户允许显示测试窗口。本轮只展示了用户明确要求的设置原型；尚未展示真机游戏测试窗口。
