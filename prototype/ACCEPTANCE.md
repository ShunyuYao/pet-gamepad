# 手柄设置交互原型验收

本文件先于原型实现建立，范围仅为可交互提案，不代表已接入宿主或完成真机适配。

## 行为

1. 首次打开显示「尚未连接」，不得把模拟设备当成真实检测结果；模拟须用户主动开启并持续有明确标记。
2. 连接入口主动开始浏览器 Gamepad 检测，未发现手柄保持等待提示；退出模拟/停止检测立即清零读数。
3. 三页可用键盘进入；页切换和主题切换不会丢失编辑内容，面板与编辑器无自动关闭。
4. 模拟按键、摇杆动作可在实时面板中观察，清零可见；实际设备 ID 仅在真实检测模式展示，原型不写宿主配置。
5. 全局／单游戏设置彼此隔离；游戏默认跟随通用设置，启用独立设置后可改键。继承状态和当前编辑范围可见。
6. 映射重复时明确列出冲突并阻止保存；修正后可保存；布局切换只改变显示名称，不改变物理位置。
7. 保存持久化仅在此原型 localStorage；重新打开仍保留；未保存修改可撤销；恢复默认先改变草稿，保存后落盘。
8. 左右摇杆死区可调并更新数值与测试区；模拟漂移明确标记；实际校准无设备时不可用，不伪造结果。
9. 实际校准要求双手离开摇杆，采样期间可取消，完成只生成建议等待用户应用；断连或停止检测取消校准。
10. 390×844 小屏与 1100×820 桌面布局不横向溢出；深浅色文字与焦点可读。

## 自动验证方式

隐藏 Electron，`show:false` 在首帧前生效；专用临时 userData，CDP Runtime 仅做定位与断言，输入用 CDP Input.dispatchKeyEvent 走 Chromium 键盘通道。不能使用像素坐标点击。截图在隐藏窗口绘制后捕获。

检测页面使用真实 navigator.getGamepads；自动化里额外覆盖的是**测试夹具**输入，报告中不计为 macOS／DualSense 真机通过。独立新进程复读持久化配置。

运行命令：`PET_HOST_DIR=/path/to/desktop-pet node tests/prototype-e2e.cjs`。由主 Agent 将其登记为 `test:prototype:e2e` 并加入交付门槛。依赖现有宿主 Electron，不安装新运行时；输出目录可通过 `PET_GAMEPAD_ARTIFACTS` 覆盖，默认 `prototype/artifacts/`。

## 实际验证（2026-09-29）

- Electron 43.3.0：交互 59 条断言、新进程持久化 11 条断言通过；读数、断连清零、冲突禁存、独立映射、切换独立设置保留草稿、布局切换不改物理绑定、死区过滤、测量取消／断连／显式应用均覆盖。
- 全程隐藏窗口、隔离临时 userData；CDP focus emulation 只用于隐藏页面的键盘交互，不作为原生 OS 窗口焦点验收。
- macOS 原生 select 的箭头键依赖系统弹出层；隐藏测试改走 Chromium 字符键 typeahead 选项匹配，不直接写 value 或派发合成 change。
- 390px 三页无横向溢出；桌面和小屏保存按钮均在视口内。已查看浅色连接页、深色校准页、手机映射页截图并修正死区圈比例和保存栏可见性。
- 存储错误、跨标签页配置冲突有处理路径，但目前未注入异常验证；真实 DualSense 连接、macOS 原生焦点、蓝牙和 USB 尚待真机验收。
